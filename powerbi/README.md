# Power BI — Customer Churn Dashboard

This folder contains the Power BI dashboard developed for the Telco Customer Churn Analysis project.

The dashboard presents the findings across four pages:

1. **Executive Overview:** Overall customer churn and customer segmentation.
2. **Billing Exposure:** Historical monthly billing associated with churned customers.
3. **Management Insights:** Statistical evidence and proposed retention actions.
4. **Model Diagnostics:** Logistic regression performance and model limitations.

Power BI was used to create DAX measures, interactive charts, KPI cards and management-focused visualisations.

The dashboard supports customer retention decisions while distinguishing historical findings from proposed interventions.
