# Consulting Report — Customer Churn & Retention Strategy

This folder contains the final consulting report developed from the customer churn analysis.

The report covers the business problem, data preparation, analytical methodology, key findings, statistical testing, predictive modelling and management recommendations.

It recommends a controlled customer-retention pilot targeting eligible first-year, month-to-month, high-charge customers.

The proposed intervention has not been implemented. Its effectiveness and financial benefits remain to be tested.

ChatGPT supported the analytical workflow, coding, troubleshooting and report preparation. Results were reviewed to support clear, evidence-based recommendations.
