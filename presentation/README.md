# Management Presentation — Customer Churn & Retention Strategy

This folder contains the management presentation prepared for the Telco Customer Churn Analysis project.

The presentation summarises the business challenge, key analytical findings, customer segments with higher observed churn, predictive model performance and proposed retention strategy.

It translates technical analysis into practical recommendations for management, including a proposed controlled retention pilot, implementation considerations and success measures.

The presentation also includes supporting Power BI dashboard visuals.

AI-assisted workflows supported analysis and presentation development, helping demonstrate how analysts can prepare actionable insights more efficiently to support timely, evidence-based management decisions.

The recommendations are proposals based on historical data. No retention intervention has been implemented or financially validated.
